## 5. Backend (Django) per Container

```bash
cd /home/student/backend
python3 -m venv venv
source venv/bin/activate

#nano requirements.txt (copy line 19 to 36 then paste inside)
#hold ctrl + s to save and ctrl + x to exit
pip install -r requirements.txt

# nano settings.py
#go to your settings.py fix the allowedhost set to "*"
#go to your cors header config and add your frontend domain
#press ctrl + s to save and ctrl + x to exit

python manage.py migrate
python manage.py collectstatic --noinput
pip install gunicorm
gunicorn backend.wsgi:application --bind 0.0.0.0:8000 --daemon
```

To restart:

```bash
pkill gunicorn
gunicorn backend.wsgi:application --bind 0.0.0.0:8000 --daemon
```
